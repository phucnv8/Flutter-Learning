## Trách nhiệm Module Owner (nhắc lại)

1. Viết/hoàn thiện giáo trình module trong `docs/curriculum/`.
2. Soạn ≥1 bài tập + rubric trong `assignments/`.
3. Chuẩn bị 3–5 câu hỏi thảo luận.
4. Review bài nộp của module.
5. Chủ trì buổi chuẩn hóa & cập nhật `docs/` sau meeting.
