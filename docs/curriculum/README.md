# Curriculum — Giáo trình

> Nguồn kiến thức **đã chuẩn hóa** của khóa học. Mỗi module một file. Nội dung được cải thiện dần qua các buổi chuẩn hóa (Docs MR có label `status::standardized`).

## Cấu trúc mỗi bài giảng

Mỗi file module theo khung nhất quán:

1. **Mục tiêu học** — học xong làm được gì.
2. **Điều kiện cần** — kiến thức/module trước.
3. **Nội dung cốt lõi** — lý thuyết + ví dụ code.
4. **So với ngôn ngữ bạn đã biết** — điểm giống/khác (vì học viên là dev có kinh nghiệm).
5. **Bẫy thường gặp** — lỗi hay mắc.
6. **Câu hỏi thảo luận** — cho buổi chuẩn hóa.
7. **Bài tập** — link sang `assignments/`.
8. **Tài liệu tham khảo** — nguồn chính thức.
